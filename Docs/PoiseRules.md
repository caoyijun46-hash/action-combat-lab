# 韧性系统规则（Poise）

版本：v1（2026-10-25）
读者：策划 / 数值 / 动画 / 程序
性质：规则层文档——只讲「玩家能感受到什么、数值怎么算」，不讲代码结构。

> 时间换算：模拟 60 tick = 1 秒；30 tick = 0.5 秒。下文未特别说明时，所有「秒」都是真实观感，所有 tick 都是模拟时间。
> 顿帧 / 慢放会拉长真实时间，但不会改变状态本身占用的 tick 数。

## 1. 一句话

韧性是角色挨打时的「架势值」。攻击削韧，削到 0 会**破韧**：角色进入一段无法行动、而且**没有无敌**的惩罚窗口；闪避也要花韧性，完美闪避把这次消耗返还。

## 2. 术语

| 术语 | 含义 |
|---|---|
| 韧性（Poise） | 每个角色自己的架势资源，范围 `[0, 最大韧性]` |
| 最大韧性（MaxPoise） | 韧性上限；热读，调低时当前值会被夹回 |
| 削韧值（PoiseDamage） | 一次命中打算扣多少韧性，写在招式中 |
| 打断等级（InterruptLevel） | 招式的「重量」，写在招式中；和霸体等级的差值影响削韧 |
| 霸体等级（ArmorLevel） | 角色对削韧的抵抗等级；v1 只影响削韧系数，不做「不硬直」 |
| 削韧系数 | 等级差换算出的倍率，有上下限 |
| 破韧（Poise Break） | 韧性归零后的特殊状态，固定时长、无无敌 |
| 回复延迟 | 最后一次削韧 / 闪避消耗后，多少 tick 才开始回复韧性 |

## 3. 设计师配置项

### 3.1 角色（CharacterData）

| 字段 | 默认 | 含义 |
|---|---:|---|
| `MaxPoise` | 100 | 韧性上限。热读；调低时当前值夹回，调高不会自动补满 |
| `PoiseRegenPerSecond` | 20 | 回复速度，点/秒 |
| `PoiseRegenDelayTicks` | 60 | 削韧/闪避消耗后多少 tick 开始回复 |
| `ArmorLevel` | 1 | 霸体等级，建议 0..3 的小整数 |
| `DodgePoiseCost` | 25 | 一次闪避消耗；不足不能闪 |
| `PoiseBreakTicks` | 60 | 破韧固定时长 |

> 武器系统尚未实装，`ArmorLevel` 先写死在角色数据里；以后由武器类型决定。

### 3.2 招式（AttackData）

| 字段 | 默认 | 含义 |
|---|---:|---|
| `PoiseDamage` | 60 | 命中一次的削韧值；0 = 这一招完全不削韧 |
| `InterruptLevel` | 1 | 招式的打断等级，建议 0..3 的小整数 |

### 3.3 全局（GlobalData）

| 字段 | 默认 | 含义 |
|---|---:|---|
| `PoiseCoefficientPerLevel` | 0.5 | 等级差每 1 级的系数变化 |
| `PoiseCoefficientMin` | 0.25 | 系数下限 |
| `PoiseCoefficientMax` | 2.0 | 系数上限 |

## 4. 核心规则

### 4.1 韧性范围

- 韧性始终夹在 `[0, MaxPoise]`。
- 削到 `0` 即破韧；**不保留负值**。
- 闪避扣费扣到 0 是合法状态，**不会破韧**——破韧只由「命中削韧」触发。

### 4.2 削韧公式

```
系数 = clamp(1 + 0.5 × (打断等级 − 霸体等级), 0.25, 2.0)
实际削韧 = 招式削韧 × 系数
```

等级差示例（默认系数 k=0.5）：

| 霸体等级 | 打断等级 | 等级差 | 系数 | 招式削韧 60 → 实际 |
|---:|---:|---:|---:|---:|
| 1 | 1 | 0 | 1.0 | 60 |
| 1 | 3 | +2 | 2.0 | 120 |
| 1 | 0 | −1 | 0.5 | 30 |
| 3 | 1 | −2 | 0.5 | 30 |
| 3 | 0 | −3 | 0.25（下限） | 15 |
| 0 | 3 | +3 | 2.0（上限） | 120 |

要点：

- **只有「收下」的命中才削韧**：被无敌挡掉（Blocked）或完美闪避（Dodged）都不削韧。
- 削韧系数**只影响韧性**，不影响 HP 伤害。
- 一次挥砍对同一目标最多结算一次削韧（和 HP 伤害共用「每挥砍每目标一次」的名单），多个 hitbox 不会重复削。
- 一招打中多个目标时，每个目标各自按自己的霸体等级算系数、各自削一次。
- `PoiseDamage = 0` 是关闭削韧的开关：不扣韧性、不重置回复延迟、不会破韧。

### 4.3 破韧

- 触发：一次命中削韧后韧性 `<= 0`。
- 破韧那一击：
  - 韧性归零；
  - **清空并拒绝设置无敌**；
  - 仍然结算 HP 伤害、击退、顿帧；
  - 事件结果仍是 `Accepted`，另带「破韧」标记。
- 破韧状态：
  - 固定 `PoiseBreakTicks`；
  - 不能攻击、不能闪避、不能跳跃；
  - 受击只结算 HP + 击退 + 顿帧；**不削韧、不进受击硬直、不刷新无敌、不延长破韧**。
- 破韧结束：韧性回满（当前 `MaxPoise`）、回复延迟清零，回到 Idle/Move。
- 破韧期间「霸体等级」显示为 -1，仅用于显示，不参与计算（v1）。
- 破韧结束那一 tick 的恢复顺序：状态先恢复正常，**跳跃可以在该 tick 恢复**；
  闪避门禁在状态机之前判断，通常要**下一 tick** 才能闪。这个不对称继承自
  Hitstun / Dodge 的既有行为。

### 4.4 闪避

- 进入要求：`当前韧性 >= DodgePoiseCost`。不够时按键无效，不会闪。
- 进入时扣 cost、记录本次实际支付，并重置回复延迟。
- 完美闪避（闪避无敌帧内躲掉命中）：返还**本次实际支付**的韧性；一次闪避最多返还一次。
- 返还不清回复延迟；返还最多加到 `MaxPoise`。
- 闪避扣费扣到 0 不破韧。

### 4.5 优先级

**破韧 > 受击 > 闪避 > 正常状态转移。**

同一 tick 又被打又按闪避：挨打赢，不扣闪避费用、不进入闪避。

## 5. 韧性回复

- 受击削韧或闪避消耗后，进入 `PoiseRegenDelayTicks` 的延迟；延迟结束按 `PoiseRegenPerSecond` 回复。
- **触发的那一 tick 永远不回复**（包括 `Delay=0`）。
- 延迟中再次削韧/消耗，会重新计时，不是累加。
- 破韧期间不回复、延迟也不递减；破韧结束直接回满并清延迟。
- Hitstun / Attack 等状态不额外暂停回复——受击后的冷却由延迟负责。

延迟语义：

| 配置 | 触发 tick | 触发 tick 回复？ | 首次回复 |
|---:|---|---|---|
| 0 | T | 否 | T+1 |
| 1 | T | 否 | T+1 |
| 60 | T | 否 | T+60 |

## 6. 无敌帧与连招的实际关系（重点）

当前角色数据：受击无敌 30 tick（0.5 秒）；当前招式总长 29 tick、取消窗口 3 tick。

| 事件 | 相对第一刀起手的 tick | 结果 |
|---|---:|---|
| 第一刀命中 | 4 | 收下，韧性 100→40，目标获得 30 tick 无敌 |
| 取消窗口起手第二刀 | 27 起手 | — |
| 第二刀命中 | 31 | 仍在无敌内 → Blocked，**不削韧** |
| 无敌结束 | 约 33 之后 | 可以再次收下命中 |
| 最早可收下的第二刀 | 30 起手 / 34 命中 | 收下，韧性 40→0 → 破韧 |
| 狂按连招的下一刀 | 54 起手 / 58 命中 | 收下，破韧 |

结论：

- **快速连砍的第二刀很可能被无敌挡掉，不削韧**。这不是 bug，是无敌帧和连招节奏的交互。
- 想稳定削韧，攻击间隔要大过无敌帧；`PoiseDamage=60` 需要两次「收下」才破。
- **破韧那一击不设无敌，破韧期间受击也不设无敌**——所以破韧后的追击才是真正的惩罚窗口，不会被无敌挡。

## 7. 时间线示例

### 7.1 两次命中破韧

角色 100 韧性、霸体 1；招式削韧 60、打断 1（系数 1.0）。

- T0 第一刀命中：韧性 100→40；受击硬直 12 tick；无敌 30 tick；回复延迟 60 tick。
- T0+60 之前：韧性一直是 40（延迟未结束）。
- 第二次「收下」的命中（按第 6 节，最早约 T0+34）：韧性 40→0，破韧。
- 破韧持续 60 tick；期间受击只掉血/击退。
- 破韧结束：韧性回满 100。

### 7.2 高霸体 vs 低打断

角色霸体 3、招式打断 1 → 等级差 −2 → 系数 0.5；削韧 60 → 30。
同一招打霸体 0 的角色 → 等级差 +1 → 系数 1.5；削韧 60 → 90。
霸体 3 对打断 0 → 系数夹到下限 0.25；削韧 60 → 15。

### 7.3 连续闪避

100 韧性、闪避消耗 25、延迟 60 tick：

- 连续闪避 4 次：100→75→50→25→0；每次重置延迟，期间不回复。
- 第 5 次闪避：韧性不足 25，按键无效。
- 停止闪避后 60 tick 开始回复，20/秒；约 1.25 秒回到 25，才又能闪。
- 如果中途完美闪避，返还 25；同一次闪避只返还一次。

### 7.4 破韧连击

- 破韧 60 tick；破韧期间受击：HP 照扣、击退照有、顿帧照有，但韧性始终 0、不会进 Hitstun、不会刷新无敌、破韧剩余时间不变。
- 破韧结束后韧性回满；下一次破韧又要重新削。

## 8. 调参指南

| 想要的效果 | 改什么 |
|---|---|
| 角色更耐打 | `MaxPoise` ↑、`ArmorLevel` ↑、`PoiseRegenPerSecond` ↑、`PoiseRegenDelayTicks` ↓ |
| 更容易破韧 | `PoiseDamage` ↑、`InterruptLevel` ↑、`MaxPoise` ↓、延迟 ↑、回复速度 ↓ |
| 闪避压力更大 | `DodgePoiseCost` ↑ |
| 闪避更宽松 | `DodgePoiseCost` ↓（0 = 闪避不花韧性） |
| 惩罚窗口更长 | `PoiseBreakTicks` ↑ |
| 等级差影响更大 | `PoiseCoefficientPerLevel` ↑ |
| 防止极端免疫/秒破 | 调整系数上下限 `PoiseCoefficientMin/Max` |

## 9. 边界配置

| 配置 | 行为 |
|---|---|
| `MaxPoise = 0` | 初始韧性 0；只要有一招削韧 > 0，第一下就破韧 |
| `PoiseDamage = 0` | 这一招完全不削韧（也不会重置回复延迟） |
| `DodgePoiseCost = 0` | 闪避不花韧性，0 韧性也能闪 |
| `DodgePoiseCost > MaxPoise` | 永远闪不出来 |
| `PoiseBreakTicks = 0` 或负数 | 破韧最短 1 tick，下一次 Tick 立即结束（不是「关闭破韧」） |

## 10. 当前版本限制

- **真霸体未实装**：霸体等级 v1 只影响削韧系数，不会让角色「不硬直」。后续块再做。
- **破韧时的 -1 仅显示**：不参与伤害/削韧计算。
- **武器系统未实装**：`ArmorLevel` 暂时写死在角色数据。
- **死亡未实装**：HP 到 0 不会死亡；破韧与 HP=0 同时发生时不特殊处理。
- **破韧使用专用击倒动画**：`PoiseBreak.fbx`（30 帧）；破韧固定 60 tick，比 clip 长时停在末帧。常规受击暂无专用 clip，暂时借 Idle。
- **顿帧会拉长真实观感**：破韧按模拟 tick 计（60 tick = 1 秒），命中顿帧会让它看起来更久。
- **同一 tick 多攻击者只结算最后一笔**：现有单攻击源限制；多敌人时可能少算削韧。
- **浮点边界**：韧性刚好等于闪避消耗时才能闪；HUD 显示整数时可能看起来「差 1」。

## 11. 调试方式

- HUD 的 Player / Actors 行显示 `poise 当前/上限`、霸体等级、回复延迟倒数。
- 命中事件行显示 `PoiseBefore -> PoiseAfter`、实际削韧、`BREAK` 标记。
- 左下角「受击测试」按钮使用它自己的调试削韧/打断等级，不受当前招式数据影响；点击间隔建议大于 0.5 秒（避开无敌帧）。
